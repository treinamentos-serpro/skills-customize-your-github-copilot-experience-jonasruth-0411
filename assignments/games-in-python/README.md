
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, listas, loops, condicionais e seleção aleatória ao criar um jogo da Forca em Python. O jogador tentará descobrir uma palavra oculta antes de esgotar as tentativas.

## 📝 Tarefas

### 🛠️ Implementar uma rodada do jogo

#### Descrição
Crie a lógica principal do jogo: selecione uma palavra secreta e permita que o jogador tente descobri-la informando letras.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar as letras descobertas e ocultar as demais, usando um formato como `_ _ _`.
- Solicitar palpites de letras e atualizar o progresso após cada palpite.
- Contabilizar e exibir quantas tentativas incorretas ainda restam.

### 🛠️ Encerrar a partida com o resultado correto

#### Descrição
Complete o fluxo da partida para que o jogo reconheça quando o jogador venceu ou perdeu e informe o resultado.

#### Requisitos
O programa concluído deve:

- Encerrar a partida quando todas as letras da palavra forem descobertas ou quando não restarem tentativas.
- Exibir uma mensagem de vitória quando o jogador descobrir a palavra.
- Exibir uma mensagem de derrota e revelar a palavra secreta quando as tentativas acabarem.
